# Deck orders by cadence first, not by overdue-ness

The deck previously ordered chores most-overdue-first, so a long-neglected long-cadence chore could sit ahead of a short-cadence chore that had only just gone overdue. We changed the primary sort key to cadence (shortest first), so a 3-day chore always outranks a 16-day chore regardless of how many days the 16-day chore has been overdue. Overdue-ness only breaks ties within the same cadence, and creation order (most-recent-first) breaks remaining ties. We considered keeping a due-today/overdue tier above cadence, and breaking cadence ties by recency instead of overdue-ness; both were rejected because they let a stale long-cadence backlog bury frequent chores, which is the exact failure mode this change exists to prevent.
